# 原图布局核对与全键盘游戏

参考用户提供的 `原图/Air75 V3 Silver  .png`，仅用于位置、尺寸及间距；没有修改原图，也没有把其绿色/黄色/橙色移植到界面配色。

官方 NuPhyIO 当前 Air75 V3 ANSI 配置确认第一行：Esc、F1–F12、截图、Insert 共 15 个连续 1u 按键，独立旋钮在最右侧第 16 个位置。其余五行延续 16u 网格，空格为 6.25u。原来的 F1 前 0.5u 及几处分组 0.25u 空隙已移除。

LED 14 是 Insert；旧显示名称“旋钮”不正确。官方 ANSI 键位数组共有 86 项，其中 3 项是隐藏的旋钮操作，排除后共 83 个可见按键。旋钮的音量减/静音/音量加是键位操作，不能作为 RGB 索引。ANSI 已确认 RGB 索引 0–82 均保持原顺序；通道 83 未被臆测成旋钮，也没有改动已有作品颜色数组。

2026-09-11 用户指定右上角显示为平面 Del 键帽：界面第 16 格使用 Del 文字替代旋钮图标，第 15 格恢复 Ins 标签。此为键帽外观调整，未给右上角增加未经验证的 RGB 索引；所有画布和缩略图共用同一个键帽组件。

来源：[NuPhy 官方驱动源码](https://drive.nuphy.io/static/js/main.23dc78ef.js)，2026-09-10 读取，SHA256 `8b8fe5fdb1c13092bd3f38476688e4435b2ffdfcca552ba4b36d5fe149f27fba`。Air75V3 模块 47501 使用布局模块 97075 的 ANSI 数组 m；官方 ISO 数组 g 的额外按键不能混用到 ANSI。

游戏采用全键盘的不规则行结构，左右为相邻按键，上下优先进入相邻行中覆盖蛇头中心的按键；没有覆盖时选最近按键。空格只占一个节点，全部 83 键互相可达。只有蛇与食物输出非零 RGB，其他主键通道和 20 个侧灯通道全部为零。退出游戏恢复原作品与侧灯模式。
