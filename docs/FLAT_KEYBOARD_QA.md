# 平面键盘图修正 — 2026-09-11

用户要求保留原来的正视平面键盘图，去掉立体感。本次为现有设计中的局部修正，没有重新设计页面或生成新的键盘素材。

## 改动与视觉核对

参考为用户此前提供的正视键盘截图 `codex-clipboard-f82bd13d-1697-4388-a653-7b22beeac173.png`；最终浏览器截图为 `design/flat-keyboard.png`，两者均使用 `view_image` 实际查看。

| 核对项 | 处理与结果 |
| --- | --- |
| 键帽、外壳 | 去掉投影、内高光和灯光晕，只保留纯色与细边框，符合本次明确要求。 |
| 按键位置 | 保留原坐标、尺寸和 83 颗可映射按键灯；后续键帽更正为索引 14 显示 Ins，右上角独立装饰位显示 Del。 |
| 图案与颜色 | 默认爱心仍为右侧 19 键，RGB 数据及动态淡出规则没有修改。 |
| 右上角键帽与侧灯 | 后续按用户要求用平面 Del 键帽替代圆形旋钮图示，保持非交互且不分配 RGB 索引；两侧灯条与几何位置不变。 |
| 页面层级与文字 | 左侧创作台子导航、工具栏和预设分类无改动；后续只更正 Ins 与装饰 Del 的键帽显示。 |
| 交互提示 | 悬停用细轮廓，选中保持绿色 2px 轮廓，键盘焦点仍清晰。 |
| 响应式 | 默认浏览器 1280×720，以及 620×640、390×844 检查；无横向溢出，小窗口不再重新加入按键阴影。 |

差异清单中的键帽投影、内高光、灯光晕及窄屏阴影均已修复，没有遗留的立体处理。用户后续明确要求右上角显示 Del，因此索引 14 的 Insert 键帽恢复为 Ins，`x=15, y=0` 的独立装饰位显示 Del，不再显示旋钮。键帽更正不改变灯光映射、字号、配色或排版；`design/flat-keyboard.png` 已更新并通过 `view_image` 核对，包含本次 Del / Ins 更正后的平面键盘图。

## 验证

- TypeScript 与 Vite 生产构建通过。
- 使用 CUA 的 IAB 浏览器实际打开生产构建；大键盘、14 个预设缩略图、动画画布与 32 个逐帧缩略图的计算样式均无阴影。
- 实际点击选择、绘制、撤销、重做；拖动 Q→W→E 后可整笔撤销。动态预设可打开并播放。浏览器没有 error 日志。
- 响应式临时尺寸已重置，测试数据与真实个人作品隔离。

操作验证还发现原有撤销快照在 React 批处理时可能读到绘制后的可变 ref。现在在笔画开始和历史入队前固定颜色快照，首次撤销与重做、三键拖动的整笔撤销均已实际验证。

本次只改键盘图样式与历史快照捕获，没有改固件协议、灯光 RGB 或预设帧。未重复前一轮实机灯效验收；该记录仍见 `PRESETS_QA.md`。
