# 三款新游戏验收 · 2026-09-11

本次加入打地鼠、记忆灯序、双人乒乓球，与贪吃蛇共用「创作台 → 游戏」入口。使用现有键位映射、灯光传输和恢复机制，未改变固件或物理按键绑定。

## 已执行

- TypeScript / Vite 生产构建通过。
- `npm test`：83 项测试全部通过。新游戏覆盖打地鼠命中、错按、漏击及30秒结束；记忆灯序暗隙、输入超时、错误反馈和完整20轮通关；乒乓双人同时按住、释放、方向抵消、碰撞、延迟帧、得分和7分胜利。
- 使用真实 HTTP 服务、游戏引擎、存储与 Hardware 适配器进行联调，HID 子进程和 Codex 适配器替换为隔离模拟。验证四游戏切换、暂停冻结、灯光背景与侧灯黑色、结束恢复原场景、纪录分开保存、断线重连。
- 注入纪录写入失败：游戏和灯光继续运行，显示纪录暂未保存，避免逐帧重复写入失败。注入断线后结束游戏：不向离线设备写帧，重连时恢复原场景；明确停止会取消待恢复场景。
- 浏览器通过 CUA 操作编译后的界面：打地鼠分别用实体键与键盘图点击命中，得分增至2；观察实际可见的记忆提示，再按正确键完成一轮；乒乓分别按住左右屏幕控件，确认球拍移动到新的物理键位；离开游戏页面再返回保持暂停，重载页面不覆盖暂停中的游戏。
- 检查1100 × 700默认内容区与720 × 520最小内容区。默认窗口可完整容纳乒乓控制区；小窗口分区移至画布下方并纵向滚动。小窗口文档宽与内容宽均705px（15px滚动条），无横向溢出。检查八键记忆控制区，控件未重叠。浏览器错误日志为空。

## 验证边界

本次联调没有访问实际 HID 键盘、用户作品库或 Codex 账号，也没有重启用户正在编辑的原生窗口。屏幕上的“已连接”仅属于上述隔离模拟环境，不能当作本轮真机验收。游戏输出始终是84项RGB数组，其中可玩物理键映射为0–82，保留通道83黑色；未把逻辑通道数当成实物可玩键数。

当前项目中的真实硬件历史验收仍见 `HARDWARE_QA.md` 与相关记录，不属于本轮新游戏的重复验证。新应用包位于 `release/pending-update/Air Studio.app`，完整交付压缩包会包含本次游戏和既有色盘、爱心、Del键帽修改。
