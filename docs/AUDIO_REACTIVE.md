# Audio-reactive lighting / 声音律动

[Documentation / 文档目录](README.md)

USB audio lighting offers ten effects: Volume Breathing, Spectrum Bars, Beat Ripples, Center Waves, Melody Waves, Note Rain, Rhythm Meteor, Twinkling Stars, Heartbeat and Bass/Treble Dialogue. Choose monochrome or multicolor, sensitivity and a noise gate. System audio uses a Core Audio process tap on macOS 14.2+; microphone mode supports the system default or a selected input. Capture stays local and is not recorded or uploaded. Bluetooth and 2.4 GHz software RGB are unavailable.

This record covers the original 1.0.16.6 implementation and later beat/multicolor checks. The 140 ms beat gate is onset detection, not guaranteed BPM or instrument recognition. Effects yield lighting ownership, stop capture on exit or source changes, and follow the shared sleep timer. Early 20 Hz statements describe that implementation; v1.0.6 raised the lighting target to 30 Hz. See the latest release QA for 1.0.23.6 validation. RGB readback is not optical calibration, and external microphone enumeration is not certification of every device.

十种效果支持单色／彩色、灵敏度与噪声门限；系统声音需 macOS 14.2+，也可用麦克风。仅本机分析，不保存上传。下方保留原固件、鼓点和彩色验收；早期刷新率为历史值，当前兼容范围见最新版本记录。

# 声音律动

入口：创作台 → 声音律动。需要 Air75 V3 USB 有线连接与已验证的 1.0.16.6 灯效固件。首次使用点击开始，按 macOS 提示授权。蓝牙、2.4GHz 不提供此功能。

## 使用

- 系统声音：macOS 14.2+ 的 Core Audio process tap，捕获电脑输出，耳机播放也可用。不会静音原有声音，不需要虚拟声卡。当前安装包最低支持 macOS 13.5，13.5–14.1 可使用麦克风模式。
- 麦克风：可选系统默认、内置或已连接的外置音频输入。缺失设备不偷偷改用其他设备；选默认时跟随系统默认输入。
- 音量呼吸：全主键区亮度随声音音量起伏，按最近峰值增强对比，让重拍明亮、弱拍明显变暗。使用较快起落，避免原压缩曲线在大音量时持续饱和；灵敏度仍可调。持续同响度纯音保持稳定，不凭空制造鼓点。
- 频谱跳动：八个对数频带从左至右排列，亮起高度随各频带能量变化。
- 鼓点扩散：用原始音量与八个频段的瞬间变化检测鼓点，由键盘中心产生短暂扩散。持续低音不会掩盖中高频的新敲击；持续纯音不会不断触发，不是精确 BPM 或乐器识别。提高「调整响应 → 灵敏度」可跟上较轻的鼓点，跳动过密时调低。
- 中心声浪：音量越高，从键盘中央向两侧展开得越远。
- 旋律波浪：亮带沿旋律流动，波纹速度和明暗随声音变化。
- 音符落雨：按八个频带的能量分布，从对应横向位置落下光点，并带有短尾迹。
- 节奏流星：声音重拍触发一道从左至右横穿键盘的流星。
- 星点闪动：音量决定星点数量，光点轻柔出现并淡去。
- 心跳爱心：使用现有 19 键爱心轮廓，每次检测到重拍产生两次明暗跳动。
- 高低音对话：左半键盘响应低音，右半键盘响应高音，亮起高度随各自频段能量变化。
- 颜色可选「单色 / 彩色」。单色使用连续色盘；彩色支持全部十种效果，频谱和落雨按频段分色，高低音对话用暖色与冷色区分左右，其余效果使用随声音流动的多色渐变。模式可在播放时直接切换，切回单色保留之前的色盘颜色。
- 颜色模式、色盘、灵敏度、噪声门限可以实时调整。静音时渐灭；选择输入源/设备前先停止。

已有用户设置默认保留单色；选择彩色后会记住，下次打开沿用。彩色只改变颜色分布，不改变鼓点检测、明暗包络、图形轮廓或熄灭行为。效果选择可在播放中直接切换，已有粒子尾迹不会带入下一种效果；静音后尾迹结束并熄灭。选择区统一为紧凑网格，小窗口自动换行，只显示当前效果说明。

期间暂停 Codex 灯光覆盖，保留任务和命令快捷键。侧灯保持关闭，不高频写入侧灯配置。统一亮灯和空闲休眠计时生效，声音本身不重置空闲时间；休眠暂停采集，唤醒后恢复。开始游戏、按键触发或其他作品会停止采集，退出游戏不会自动重开麦克风。停止律动恢复接管前的键盘灯光。

## 数据与生命周期

音频 PCM 只在签名的 NuPhyLab 主进程内存中处理，不写录音、不上传。原生分析器使用 2048 点 Hann 窗和 DFT，输出 RMS 与八个频带能量。每约 50 ms 最多提交一组摘要；只保留最新待发送结果，避免旧帧积压。现有 D8 RAM RGB 通道约 20 Hz 调度，颜色相同不重复发送。

采集会话使用独立随机标识，停止或换源后的旧数据被拒绝。静音可能没有系统回调，原生端发送状态心跳，不把静音当断线；过期声音按静音渲染。原生主进程失去后端联系时停止采集。按键或音频设备断开、输出失败、切换效果来源、退出或电脑休眠均有清理路径。仅保存来源、设备、颜色和效果设置，不保存正在录音的状态，重开软件不会自动采集。

不声称支持每个播放器的受保护内容、外置设备或复杂音频路由；无法采集时显示操作提示。当前只验证本机系统音频和 Mac 内置麦克风，外置麦克风通过系统设备枚举与选择路径支持。

- 系统声音：真实 Core Audio 采集 120 Hz、1 kHz、4 kHz 测试音，主频带与输入对应。连续静音 12 秒保持连接、全部主键熄灭，随后声音恢复时正常出帧。

- 内置麦克风：实际输入驱动音量呼吸、83 键点亮，84 个通道回读一致。没有实物外置麦克风验收，不将设备枚举支持等同于所有外置设备已验证。

## 十种效果与呼吸增强验收

- 完整串行回归 206 项通过、0 失败。新增测试覆盖强弱音乐的呼吸对比、10 种互不相同的动态输出、爱心双拍、左右频段分离、中英文目录、播放中切换与旧尾迹清理。一次并行回归中的旧触发器短计时用例失败，单独复查和完整串行复查均通过；未修改触发器逻辑或放宽其断言。
- 呼吸对比测试分别使用较小和较大的输入音量：白色上限为 255 时，重拍超过 230、弱拍低于 65，对比超过 170。实际系统音频验证中，用户选择的颜色最高通道为 158，呼吸能够达到这一峰值，弱处明显变暗。
- 10 种效果逐一运行于真实 USB 键盘，均产生连续变化的 RGB 帧，逐一回读 84 个通道完全匹配；心跳爱心最多亮 19 键。静音 3 秒后全键熄灭，采集会话保持正常，停止时恢复原灯光。
- 已检查中文与英文的 10 项紧凑网格、小窗口颜色及音源区域；所有效果保持用户选择的色相，不自动添加彩虹。

## 鼓点响应改进（2026-09-22）

检测改为在亮度压缩之前分析原始 RMS / 八频带，避免大音量或持续低音将强弱变化压平。各频带分别追踪上升与回落，同一击的持续声音不重复触发。最短触发间隔由 220 ms 缩短为 140 ms；灵敏度同时控制较轻敲击的识别门槛。鼓点扩散、节奏流星和心跳爱心共用此改进，声音传输和键盘刷新率不变。

- 持续低音叠加每 500 ms 的鼓点：10 秒内由原来的 3 / 20 次触发改善为 20 / 20 次。
- 每 200 ms 的快节奏：10 秒内由 26 / 50 次改善为 50 / 50 次。
- 真实 Swift 分析器处理合成 PCM，44.1 / 48 kHz、500 / 200 ms 两种节奏均无漏拍，检测误差不超过一帧（50 ms）。
- 验证了灵敏度调整、持续纯音、微小噪声、门限下静音、过期声音和恢复首拍。以上为可重复的合成信号验证，不代表所有歌曲都能逐拍识别。

本机验收：完整串行回归 277 项通过，前端构建通过。通过真实 Core Audio 系统音频采集播放短合成鼓点，Air75 V3（1.0.16.6）上鼓点扩散、节奏流星、心跳爱心分别观察到 60、32、24 个不同的非黑 RGB 帧；每种效果回读 84 个主区通道全部匹配。静音后尾迹熄灭，停止采集后原灯光恢复成功。用户音源、效果、颜色、灵敏度和作品均保持原设置，测试音在验收后删除。界面已检查鼓点响应说明和原有灵敏度控件。
