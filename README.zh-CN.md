# NuPhy Lab · AIR75 V3＋Kick75

以后统一维护一个 **NuPhy Lab 双适配版**，同时支持 **AIR75 V3 和 Kick75（ANSI）**。连接哪一把键盘，软件就自动识别哪一把；不再单独维护 AIR 专用版。

本仓库网址继续作为固定的市场分享入口。当前双适配版的源码、安装包和应用更新统一在 **[NuPhyLab-next](https://github.com/bohu8264/NuPhyLab-next)** 发布。上方链接始终打开最新正式发行版，市场无需逐次更换分享地址。

## 安装与更新

1. 先退出旧 NuPhyLab。打开 DMG，将 **NuPhy Lab** 拖入「应用程序」。
2. 只保留一个 Lab 应用。确认新版可正常打开后，将旧应用移到废纸篓；保留本机应用数据，作品和设置会继续使用。
3. 用 USB 数据线连接 AIR75 V3 或 Kick75，切到有线模式。按软件提示完成系统授权和固件检查。

**旧 1.0.11／1.1.x 用户需要手动安装一次新版。** 旧版本没有新版更新器，不能自动完成这次迁移。安装双适配新版后，软件会自动检查更新，也可在应用菜单或设备页点击 **「检查更新」**。

逐键灯效、动画和游戏需要 USB 连接；AIR75 V3 另支持蓝牙快捷控制。键盘固件按软件引导前往官方 NuPhyIO 升级。

## 保留的功能

- 逐键 RGB 绘图、动画与本地作品库。
- 按键触发、键盘游戏与声音律动。
- Codex／Claude Code 任务状态灯和快捷操作。
- 两款键盘自动识别及各自布局。
